# 🌑 Letswhim Framework v1.0
> "Let's just start."

A modern, clean, and minimalist full-stack framework built for **GUUG Labs**.

## 🚀 Core Features
- **Dynamic Routing**: No manual route definitions.
- **Hot-Whim**: Real-time browser reloading on file save.
- **L-Lang Parser**: Separate logic and template blocks for cleaner code.
- **Master Shell**: Global aesthetic management via `compiler.js`.

## 🛠️ Getting Started
1. Install dependencies: `npm install`
2. Start development: `npm run dev`
3. Create new page: `npm run make [page-name]`

## 📁 Folder Structure
- `/public`: Static assets (images, logos).
- `server.js`: The Hono-powered engine.
- `compiler.js`: The parsing & shell engine.
- `*.letswhim`: Your minimalist project files.

## 🛠️ Perintah
- `npm run dev`: Jalanin server dengan Hot-Reload.
- `npm run make [nama]`: Buat halaman baru otomatis.

## 📁 Struktur
- `/public`: Tempat logo.png dan favicon.svg lo.
- `*.letswhim`: File proyek lo.
